# Geração Tech - IEL | Meus Primeiros Passos

Bem-vindo ao meu primeiro repositório!

Este espaço foi criado para registrar a minha jornada e evolução no curso **Geração Tech**, oferecido pelo **IEL**. Aqui vou guardar todas as minhas atividades, exercícios e projetos práticos enquanto mergulho no mundo do desenvolvimento **Full Stack**.
